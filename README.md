# Personal Assistant memory

This private repository holds what one person's Tierra Personal Assistant has learned about them: their email rules, which items they have moved off asks first, their preferences, a short memory file and the lessons quarantine.

Every file except this README is scrambled (AES-256-GCM), one `<name>.enc` file per pack file. Only the assistant's own box holds the key, and Tierra keeps no spare copy, so the files are unreadable without that box. If the box is destroyed (for example when the person leaves Tierra), the files can never be read again; the person may keep or delete this repository.

Changes arrive only as commits from the assistant: after the person's yes on a card in Slack, or the nightly lessons commit. Each one can be seen in the history. To see the rules or the memory in plain words, ask the assistant in Slack ("show me my email rules", "what do you remember about me").
